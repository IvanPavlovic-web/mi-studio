# MI Studio - Visual & Print Studio

![Screenshot sajta](mistudio.jpg)

Made with vanilla JavaScript, HTML and CSS
---

## Installation

### Method 1: Clone with Git
```bash
git clone https://github.com/IvanPavlovic-web/mi-studio.git
cd mi-studio
```
---
### Method 2: Download ZIP
1. Click the Code button and select Download ZIP
2. Extract the ZIP file to your preferred location
3. Navigate to the project folder
4. Open index.html, no additional installation required as it runs directly in the browser
---
## Technology Stack
- **Frontend** - HTML5, CSS3, JavaScript
- **Compatibility** - All modern web browsers
- **Deployment** - Static website
