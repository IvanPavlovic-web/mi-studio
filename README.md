# MI Studio - Visual & Print Studio

![Screenshot sajta](mistudio.jpg)

## Overview
MI Studio is a static website built with vanilla JavaScript, HTML5, and CSS3, showcasing visual and print design services. Fully compatible with modern browsers.  

## Installation

**Option 1: Clone Repository**
```bash
git clone https://github.com/IvanPavlovic-web/mi-studio.git
cd mi-studio
```
**Option 2: Download ZIP**

1. Click the **Code** button and select **Download ZIP**  
2. Extract to your preferred location  
3. Open `index.html` in a browser (no installation required)  

## Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript  
- **Deployment:** Static website
